## 中文

八语言患者头痛日记实验原型：Android首次离线使用、加密备份、浏览器/PWA、Windows一键启动、患者授权下的医生建议与可复核摘要。源码可见；个人非商业学习与实验可用，机构及商业使用须书面授权。

## English

Eight-language patient headache diary prototype: offline-first Android, encrypted backups, browser/PWA and Windows access, patient-authorized clinician advice and transparent summaries. Source-available; institutional and commercial use requires written permission.

## 使用入口亮点 / Access highlight

当前候选为Web/服务端0.8.2与Android 0.1.0-preview。Android安装包可首次离线建立档案、连续记录并加密备份；联网协作需要另行部署HTTPS服务。Windows便携包单独提供一键启动和运行环境，纯源码需Node.js 24。浏览器/PWA保留；小程序是接入准备代码。

The current candidate is web/server 0.8.2 and Android 0.1.0-preview. Android can create a profile, record and back up without first-use connectivity; connected collaboration requires a separately deployed HTTPS service. The Windows portable bundle supplies the runtime and one-click startup; source users need Node.js 24. Browser/PWA remain available; mini-programs are integration scaffolds.
