## 中文

八语言患者头痛日记实验原型：初始化后可连续多日离线记录、弱网同步；提供Windows一键启动、可选HTTPS手机部署、可复核摘要与模拟随访/提醒。源码可见；个人非商业学习与实验可用，机构及商业使用须书面授权。

## English

Eight-language patient headache diary prototype with multi-day offline recording after setup, weak-network sync, Windows startup, optional HTTPS mobile deployment, transparent summaries and simulated follow-up/reminders. Source-available; institutional and commercial use requires written permission.

## 使用入口亮点 / Access highlight

Windows一键启动、浏览器直接使用与可选小程序/PWA入口：电脑默认本机可用；手机已提供可选HTTPS代理配置，仍需维护者部署真实网址、证书并完成真机验收。小程序待接入和平台验证，PWA安装待验收。Windows便携包单独提供，纯源码需配置Node.js 24。

One-click Windows startup, browser use and optional mini-program/PWA entry points. Default host-computer access is available. Mobile HTTPS proxy configuration is supplied, but actual hosting, certificates and physical-device acceptance remain operator tasks. Mini-program integration/approval and PWA installation validation remain pending. Windows launchers/runtime are in the separate portable delivery; source users need Node.js 24.
