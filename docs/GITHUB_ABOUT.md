## 中文

八语言头痛日记实验原型：患者自主提醒（本机模拟）、每日记录、可复核的医生摘要、语音辅助与模拟随访。源码可见；个人非商业学习与实验可用，机构及商业使用须书面授权。

## English

An eight-language headache diary research prototype featuring patient-controlled reminders (local simulation), transparent summaries, reviewed voice input and simulated follow-up. Source-available; institutional and commercial use requires written permission.

## 使用入口亮点 / Access highlight

Windows一键启动、浏览器直接使用与可选小程序、PWA入口：电脑本机已可用，手机服务待部署，小程序待接入及平台验证，PWA安装待验收。Windows便携包单独提供，GitHub纯源码仍需配置Node.js 24。

One-click Windows startup, direct browser use, and optional mini-program/PWA entry points. Host-computer access is available; mobile service deployment, mini-program integration/approval and PWA installation validation remain pending. Windows launchers/runtime belong to the separate portable delivery; source users need Node.js 24.
