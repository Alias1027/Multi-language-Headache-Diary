# 中文使用说明 — 0.6.1

**2026-10-18 已发布：** [官方仓库](https://github.com/Alias1027/Multi-language-Headache-Diary--) · [v0.6.1 实验预发布版](https://github.com/Alias1027/Multi-language-Headache-Diary--/releases/tag/v0.6.1) · [发布标签自动测试结果](https://github.com/Alias1027/Multi-language-Headache-Diary--/actions/runs/39118500923)。Ubuntu 与 Windows 各通过137项自动测试，以及发布检查、源码打包与解压核验。101项浏览器检查是此前本机合成数据证据，不属于远程 CI。

用于合成病例演示。八语言界面可用；语音转写与字段提取仍限中文、英文，需配置适配器才能自动转写。

## 亮点功能：患者自主提醒

在“设置 → 提醒”中，按自己的生活节奏选择每周提醒日、每日时间及时区、消息语言与内容。可启用免打扰、暂停至指定日期，并在当天状态填写完整后跳过提醒；也可随时关闭。

保存设置后点击“测试已保存计划”，查看下方提醒历史。**本版只在本机模拟，邮件、短信、PWA、微信和支付宝不会实际发送。** 真实渠道需另行接入与授权。联系方式与提醒历史独立加密保存，不进入医生摘要或临床共享；尚未验证提醒能提高依从性。详见[提醒规则与接口](REMINDERS.md)。

## 下载哪一种包？

从 [v0.6.1 Release](https://github.com/Alias1027/Multi-language-Headache-Diary--/releases/tag/v0.6.1) 下载 [Windows x64 便携包](https://github.com/Alias1027/Multi-language-Headache-Diary--/releases/download/v0.6.1/headache-diary-windows-x64-0.6.1.zip) 或 [纯源码包](https://github.com/Alias1027/Multi-language-Headache-Diary--/releases/download/v0.6.1/headache-diary-source-0.6.1.zip)，并用同页 [SHA256SUMS.txt](https://github.com/Alias1027/Multi-language-Headache-Diary--/releases/download/v0.6.1/SHA256SUMS.txt) 核对 SHA-256。Windows x64便携包带运行环境和一键入口；纯源码需自行安装Node.js 24。两者不含既有账号、数据、音频或密钥。

便携包先全部解压到新文件夹，再运行 `Start.cmd`；不要在压缩包中直接启动或覆盖原有数据。详细步骤见[双语下载与首次使用](WINDOWS_PORTABLE.md)。感兴趣的用户可阅读[测试邀请](TEST_INVITATION.md)，使用[合成任务与反馈格式](RELEASE_PARTICIPATION.md)；机构及商业用途仍须书面授权。

## 启动与关闭

便携交付目录：双击 `Start.cmd`，浏览器打开 http://127.0.0.1:8765；结束时使用 `Stop.cmd`。`Test.cmd` 运行自动测试和发布检查。GitHub源码：安装Node.js 24后，执行 `npm start`，按Ctrl+C停止。两个副本默认使用相同端口，各自保留数据，不要同时启动。

默认无需联网、密钥或模型。`.env.example`只说明可选配置，不自动加载。设置 `HD_DATA_DIR` 可把私有数据放在源码目录外。停止服务后再备份整个数据目录；数据库和密钥必须一起保管，不能上传仓库。

## 体验合成病例

选择“体验合成病例”会新建独立的虚构账号。2026年9月1–28日示例为23/28天已记录、8个头痛日、7次发作、5个急性用药日；覆盖率82.1%。演示不会提供可重复输入的邮箱/密码，请用同一浏览器会话继续，不要退出或清除站点数据；会话失效时可重新体验新合成病例，需保留结果请提前导出。自行注册的实验账号才可使用自己设置的邮箱/密码重新登录。

本机新账号可以填写虚构邮箱（如 `demo@example.invalid`）和10–128位密码。在“设置 → 实验与调试”的本地模拟邮箱查看验证码。不会发真实邮件；此流程不能验证邮箱所有权。当前没有找回密码功能。

首次记录前，可在设置中选择观察开始日与报告时区；已有记录后这两项锁定。事件输入采用设备时区，报告归日采用报告时区。

## 我的日记

1. 概览显示已保存记录；在“这一天的状态”选择日期，分别确认头痛和急性用药状态。
2. 有头痛或用药时，展开的初始表单帮助填写。未触碰的自动空表单不保存；开始填写后需补全相应字段。只知道当天状态时可以先保存状态。
3. 头痛发作须确认部位、性质、时间及临床评估字段；未知、无、不适用应按含义选择，不能把漏填当作无。持续发作可更新已有记录，避免每天重复新增。
4. 确认预防治疗实际执行及活动影响；未使用预防治疗请选择“不适用”，无方案变更无需添加药物方案。医生建议不会自动生成实际服药记录。
5. 核对后点击“核对并保存本次记录”。同组记录一起保存；一条有错误时整组不写入，保留填写供修改。

自然月按上月1日至月末；最近4周按截至昨天的28个完整日。两者日期和天数可能不同，报告保留确切起止日期。

## 语音辅助

点击浮动语音按钮，录音、上传音频或输入/粘贴中英文文字。开始/停止为同一录音控制；新建记录只在已有内容时作为次级操作出现。

原件加密保存在本机。自动转写需本机或可选云端适配器；外部处理需要逐次确认。整理后逐项查看原文依据，确认日期、侧别、药物、剂量和否定表达，再填入对应分区。填写正式记录仍需统一保存。下载的音频、导出JSON是明文。详情见 [语音说明](VOICE_INTEGRATION.md) 与 [模型接口](MODEL_INTEGRATION.md)。

## 报告与随访

报告语言默认跟随界面，也可独立选择；切换界面不翻译原文、不改写已有报告。生成摘要后查看记录覆盖率、未知天数、发作、实际用药和治疗时间线。

合成病例可进入模拟医生工作台，依次填写医生评估、模拟治疗方案和回访；确认后患者视图可查看与反馈。修订保留版本；这里没有真实处方和医师资质认证。

## 设置、共享与离线

设置集中管理偏好、共享授权、回执、同步和实验工具。授权只面向本机模拟医院；接收回执不表示真实医生已阅读。撤销影响后续共享，不撤回已接收快照。服务关闭期间不执行排程。

首次成功访问后，页面资源可离线缓存；草稿与待同步队列在浏览器中加密暂存。恢复服务后可点同步，重试不重复创建同组记录。冲突时先导出草稿并核对已有记录，不自动覆盖历史内容。清理站点数据会删除浏览器离线内容；退出会清理账号缓存。演示应使用可信设备。

更多功能边界见 [完成情况](IMPLEMENTATION_STATUS.md)、[安全说明](../SECURITY.md) 与 [验收记录](VALIDATION.md)。

设置新增患者主动启用的提醒计划（星期、时间及时区、语言、内容、联系方式、渠道、免打扰、暂停和当天填写完整后跳过）。本版只生成本机模拟记录，不发送外部消息。提醒联系方式与历史加密保存在账号个人配置中，不进入医生视图、临床报告和共享载荷。原有临床记录保持不变；没有主动保存新提醒设置的账号不会启动后台提醒。语音悬浮入口已放大，保留八语言与 RTL 适配。详见 [提醒接口及使用边界](REMINDERS.md)。

## 0.5.3 使用体验修复

- 提醒内容尚未保存时，提交其他设置或打开会刷新的数据操作会先提示；选择取消即可继续编辑。
- 在横屏或较低窗口中，语音浮窗使用可用屏幕高度；通过右上方的关闭按钮收起，再继续填写日记。
- 无待办任务时减少后台磁盘写入，不改变定时提醒和报告共享规则。

## 0.6.0 患者端优化

本项目服务患者连续记录及随访反馈，不建设完整病历、病程记录或处方执行平台。新增患者转录方案与来源、实际执行反馈、前后各28天日记观察及逐项语音候选复核。语音模型仅保留接口和兼容扩展，本版不要求安装或落地识别模型。具体步骤、缺失处理、共享范围和限制见[患者工作流](PATIENT_WORKFLOW.md)。

## 0.6.1 逐条反馈与就诊摘要

1. 患者在“方案与执行”填写当前方案的执行情况、实际开始日期、主观变化、困难和不良反应。每次提交新增一条，不覆盖上次，也不自动记为实际服药。
2. 在每张方案卡片下的“反馈历史”点击日期，逐条查看完整内容。最近一次默认展开；历史方案保留原反馈，可按“前一版本”追溯调整及原因。
3. 模拟医生在同一“方案与执行”查看历史反馈和日记观察；有新反馈时点击“刷新随访”。确认后的方案通过“创建修订版本”调整并填写理由。患者转录始终保留患者来源，不变成医生确认。
4. 患者或模拟医生点击“生成摘要”，新报告纳入生成时全部已发布方案版本、患者反馈、医生评估和回访快照。上方日期仅筛选日记统计，随访附录不按这些日期筛选，并标明生成时间和数据版本。医生草稿不进入报告。
5. 点击打印可通过浏览器另存PDF；打印时展开全部报告历史，下载JSON包含同一快照。后续变化不改写旧报告，页面提示重新生成。既往报告缺少随访附录时有明确说明。

当前模拟共享只发送日记摘要，不含新增方案和反馈；打印和下载的医生摘要含随访附录。真实医师认证、机构接入和消息送达仍需后续部署；反馈和回执不表示实时监护。详见[患者工作流](PATIENT_WORKFLOW.md)和[产品对照](PRODUCT_COMPARISON.md)。
